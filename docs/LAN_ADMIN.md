# 局域网部署与加币流程

## 启动

双击项目根目录的 `run.bat`。窗口保持打开即代表服务器正在运行。

启动后会显示：

- `本机游戏`：只给服务器所在电脑使用。
- `本机后台`：只给服务器所在电脑管理加币。
- `局域网游戏`：发给同一 Wi-Fi 或同一网段内的玩家。

## 玩家流程

1. 玩家打开 `局域网游戏` 地址。
2. 底部会显示玩家号。
3. 玩家把玩家号发给管理员。
4. 管理员在本机后台给该玩家号加币。
5. 玩家端会自动刷新余额，也可以刷新页面立即同步。

游戏必须通过服务器地址访问，不能直接打开本地 `index.html` 文件。只有通过 `http://...:3000/` 进入时，玩家才会进入同一个共享渔场。

同一局域网内的玩家会看到同一批鱼。自己的炮台固定显示在下方，其他在线玩家的炮台显示在上方。
每个房间最多支持 4 个玩家同时游戏。玩家本机视角固定把自己放在下方，其他玩家会按相对座位显示在左侧、上方和右侧；其他玩家开火时会同步显示子弹轨迹。

房间内左侧的房间号可以点击复制，方便发给其他玩家；`鱼图鉴` 会显示当前配置中的鱼种、固定价值、血量和速度。
渔场里包含更多大鱼和 BOSS，例如鬼影魟、凤尾神鱼、巨鲸、雷龙王、金鲸王和玄冥黑龙。

渔场实时数据通过 WebSocket `/ws` 同步，但不再高频下发整场鱼坐标。鱼群路径和子弹运动由前端本地模拟，服务端只同步鱼生成/移除、其他玩家炮台状态、玩家号、金币余额、开火方向和命中结算事件。直接打开本地文件不会建立 WebSocket。

房间使用服务端统一 tick、事件 seed 和事件 ID。鱼位置按 `spawnTick + 路径参数` 计算，子弹按 `fireTick + 方向` 固定步进，命中飘字和爆炸按 `hitTick + seed` 播放。每个玩家本机视角仍会把自己映射到底部，所以屏幕坐标允许不同，但同一房间里的鱼、子弹、命中结果和飘字事件来自同一份世界事件。

鱼的生成、血量、捕获和奖池仍由服务端统一结算，客户端只发送自己的炮台角度、锁定/自动开火状态、开火扣币和命中鱼 ID。

## 管理员流程

1. 在服务器电脑打开 `http://localhost:3000/admin`。
2. 在玩家列表里找到玩家号，点 `填入`。
3. 输入加币数量。
4. 点 `加币`。

后台右上角的 `清理临时账号` 会删除金币为 0、无充值、无消费、无捕获记录并且当前不在线的空账号。已经加过币或有游戏记录的玩家不会被这个按钮删除。

玩家列表的 `改名` 可以修改游戏内显示名称；`删除` 可以手动删除单个离线账号，在线玩家会被服务端拒绝删除。

## 数据

玩家余额保存在 `data/players.json`。备份这个文件即可备份玩家余额。

玩家浏览器本地只保存当前账号凭证：`fishArcade.playerId`、`fishArcade.playerToken` 和 `fishArcade.roomId`。这些数据按访问来源隔离，所以 `http://localhost:3000/`、`http://局域网IP:3000/` 和直接打开 `file:///.../index.html` 会被浏览器当成不同来源，可能生成不同玩家号。清空浏览器数据、无痕模式、不同浏览器配置文件，或后台删除了该玩家号后再次进入，也会生成新账号。

不要手动编辑运行中的 `players.json`；如果必须编辑，先关闭服务器窗口，修改后再重新启动。

## 常见问题

### 玩家打不开局域网地址

确认玩家设备和服务器电脑在同一个局域网，并允许 Windows 防火墙放行 Node.js 的专用网络访问。

### 后台在玩家手机上打不开

这是预期行为。后台和加币接口限制为本机访问。

### 玩家显示金币不足

后台给该玩家号加币；玩家端通常会在 5 秒内同步余额。

## 房间和 RTP

玩家端打开游戏后会先停在房间界面。一个玩家点“新建房间”后，把 6 位房间号告诉其他玩家；其他玩家输入房间号后加入同一个渔场。

每个房间独立维护鱼群、玩家列表、奖池和 RTP。开火扣除的游戏币会按目标 RTP 进入该房间奖池，捕获奖励只由服务端命中结算发放。

MISS 概率也在服务端计算。每次子弹碰到鱼后，服务端会按炮值、鱼倍率、房间奖池和当前 RTP 决定这次是否正常扣血；未通过才返回 `effective:false`，客户端只负责显示 MISS。

默认目标 RTP 为 97%。MISS、暴击和鸿运爆捕都在服务端计算：MISS 不扣血，暴击按 2-10 倍炮值扣血，鸿运爆捕会直接捕获目标并播放强化爆炸和飘字特效。是否发奖仍受房间奖池和 RTP 限制。

技能也由服务端扣币和结算。`爆炎弹` 会对目标点附近多条鱼结算范围伤害，`龙魂激光` 会对直线上的鱼结算伤害。

为避免“先开小炮垫血，再切大炮收割”的问题，服务端现在按炮值扣鱼血，并在鱼生成时锁定固定金币价值。捕获奖励不按最后一炮或倍率重算，不能把低成本伤害按最后一发大炮倍率结算。
