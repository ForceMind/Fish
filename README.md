# 国潮像素捕鱼

这是一个可在局域网内运行的 H5 捕鱼游戏。玩家用浏览器进入游戏，本机通过管理后台给玩家加游戏币。

## 快速启动

1. 安装 Node.js 18 或更高版本。
2. 双击 `run.bat`。
3. 启动窗口会输出两个地址：
   - 本机游戏：`http://localhost:3000/`
   - 本机后台：`http://localhost:3000/admin`
4. 同一局域网内的玩家访问窗口里显示的 `局域网游戏` 地址。

服务器默认监听 `0.0.0.0:3000`。如需改端口：

```powershell
$env:PORT=8080; node server/server.js
```

不要直接打开本地 `index.html` 文件；共享渔场、玩家余额、其他玩家炮台都需要通过服务器地址 `http://...:3000/` 访问。

## 玩法调整

- 炮塔已上移到操作栏上方，不再被底部 UI 遮挡。
- `锁定` 是独立按钮，默认关闭；开启后会自动锁定当前倍率最高的鱼。
- 锁定开启时，点击其他鱼会切换锁定目标。
- `锁定` 和 `自动开火` 放在炮台切换控件旁边，可单独开启或关闭。
- 已去掉 `Fire` 按钮，点击水域立即开火，长按水域持续开火。
- 锁定目标时，子弹会追踪锁定鱼、穿过其他鱼，只命中当前锁定目标；目标游出可见渔场或被捕获后会自动切换到下一个可锁定的高倍率目标。
- 鱼的移动增加了横向、斜向、垂直入场路径，以及波浪、折线、俯冲、漂移和弧线等路径；上下晃动幅度已降低。
- 增加鬼影魟、凤尾神鱼、巨鲸、雷龙王、金鲸王、玄冥黑龙等大鱼和 BOSS。
- 命中结果包含 MISS、暴击和鸿运爆捕：MISS 不扣血，暴击按 2-10 倍炮值扣血，鸿运爆捕会直接捕获目标；是否触发和是否发奖仍由服务端按奖池/RTP 结算。
- 增加 `爆炎弹` 和 `龙魂激光` 技能，使用时会扣除金币并由服务端结算范围伤害。
- 顶部不再放状态 UI，玩家号、金币、倍率、连击全部移动到底部。
- `+` / `-` 按钮放在炮台两侧，用来切换炮台；炮台外观和炮值会一起变化。
- 局域网玩家进入同一个渔场，实时渔场同步改为 WebSocket；房间最多支持 4 个玩家同时游戏。自己的炮台永远在下方，其他玩家按人数显示在上方、左侧和右侧，并显示玩家号、金币和炮口角度。
- 其他玩家开火会同步显示远端子弹轨迹。
- 鱼群路径和子弹运动由前端本地模拟；服务端只同步鱼生成/移除、玩家状态、开火方向和命中结算事件，避免高频下发整场坐标。
- 房间使用服务端统一 tick、事件 seed 和事件 ID：鱼位置按 `spawnTick + 路径参数` 计算，子弹按 `fireTick + 方向` 固定步进，命中飘字和爆炸按 `hitTick + seed` 播放，降低不同帧率导致的偏差。
- 点击房间号可复制当前房间号，`鱼图鉴` 可查看鱼种、固定价值、血量和速度。

## 玩家买币与后台加币

玩家第一次进入游戏会生成一个玩家号，例如 `P8A31F2`。默认初始金币为 `0`，需要本机后台加币后才能开火。

后台地址只允许本机访问：

```text
http://localhost:3000/admin
```

在后台输入玩家号和加币数量，提交后玩家端会在数秒内同步余额。玩家捕获鱼后，服务端会记录中奖金币、累计购买、累计消耗和累计捕获。

后台的 `清理临时账号` 只会删除金币为 0、无充值、无消费、无捕获且不在线的空账号，用于清掉测试时生成的大量临时号。

玩家列表的操作列支持 `改名` 和 `删除` 单个账号；删除单个账号同样只能在玩家离线时执行，避免影响正在房间里的连接和余额同步。

如果想给新玩家默认试玩金币，可设置环境变量：

```powershell
$env:STARTING_COINS=1000; node server/server.js
```

## 文件结构

```text
index.html                 游戏入口
admin.html                 本机管理后台
src/styles/game.css        游戏样式
src/styles/admin.css       后台样式
src/js/game.js             游戏循环、输入、锁定、开火、结算
src/js/renderer.js         Canvas 绘制
src/js/api.js              玩家余额 API 客户端
src/js/config.js           鱼、炮、概率配置
src/js/utils.js            通用工具
src/js/admin.js            后台交互
server/server.js           静态资源服务器与余额接口
data/players.json          运行时自动生成的玩家余额数据
run.bat                    Windows 一键启动
```

浏览器本地账号凭证保存在 localStorage 的 `fishArcade.playerId` 和 `fishArcade.playerToken`。同一浏览器如果用 `localhost`、局域网 IP、`file:///` 等不同地址进入，会因为来源不同而生成不同玩家号。

## 局域网注意事项

- 电脑和玩家设备需要在同一个局域网。
- Windows 防火墙如果提示拦截 Node.js，需要允许专用网络访问。
- 管理后台和加币接口仅允许本机访问，不会开放给局域网玩家。
- 当前结算适合局域网小范围试玩，不建议直接暴露到公网。

## 房间与奖池

- 玩家打开游戏后必须先新建房间，或输入 6 位房间号加入已有房间。
- 每个房间都有独立鱼群、在线玩家、奖池和 RTP 统计，不同房间互不影响。
- 开火扣除的游戏币会按房间目标 RTP 计入奖池，命中和捕获由服务端统一结算。
- 默认目标 RTP 为 97%。MISS、暴击和鸿运爆捕概率都在服务端计算；未通过有效命中才返回 MISS，通过后可能触发 2-10 倍暴击或鸿运爆捕。奖池/RTP 主要约束最终捕获奖励。
- 技能也在服务端扣币和结算，`爆炎弹` 命中范围内多条鱼，`龙魂激光` 命中直线上的鱼。
- 鱼的血量按炮值扣减，不再是每发子弹固定扣 1 点；先用小炮垫血再切大炮不会获得低成本高倍结算。
- 每条鱼生成时会锁定固定金币价值，捕获奖励不再按最后一炮或倍率重算，并受房间奖池和目标 RTP 约束。本项目只用于虚拟游戏币娱乐，不包含现金兑付。
